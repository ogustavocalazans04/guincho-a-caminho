# 🚗 Guincho a caminho!

## 📖 Sobre o projeto

O **Guincho a caminho!** é uma aplicação desenvolvida como parte de um projeto de extensão acadêmica, com o objetivo de facilitar e agilizar a solicitação de serviços de guincho.

A proposta é oferecer uma solução simples e intuitiva para que usuários possam solicitar atendimento, consultar informações sobre seus veículos, acompanhar serviços e validar informações relacionadas ao seguro.

O projeto está sendo desenvolvido em equipe, utilizando tecnologias modernas para aplicações mobile.

---

## 🎯 Objetivos

- Facilitar a solicitação de serviços de guincho;
- Permitir uma solicitação de emergência de forma rápida;
- Organizar informações dos veículos do usuário;
- Permitir o agendamento de serviços;
- Disponibilizar histórico de comprovantes;
- Possibilitar a validação de informações do seguro;
- Desenvolver uma solução tecnológica voltada para uma necessidade real dos usuários.

---

## 📱 Funcionalidades

### 🚨 Socorro em 1 toque
Permite ao usuário acessar rapidamente a solicitação de um serviço de emergência.

### 🚙 Meus veículos
Área destinada ao cadastro e gerenciamento dos veículos do usuário.

### 📅 Agendar guincho
Possibilidade de solicitar um serviço de guincho para uma data e horário definidos.

### 📄 Histórico de comprovantes
Permite consultar o histórico relacionado aos serviços realizados.

### 📍 Solicitação de guincho
O usuário pode informar sua localização e solicitar um guincho, visualizando uma estimativa do serviço.

### 🛡️ Validação de seguro
Área destinada à consulta/validação das informações relacionadas ao seguro do veículo.
